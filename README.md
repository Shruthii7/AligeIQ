# AligeIQ

A personal finance intelligence web application that helps users track transactions, monitor budgets, manage financial goals, and understand their spending through interactive analytics.

## Features

### Transaction Management
- Add income and expense transactions
- Edit transactions
- Delete transactions
- Search transactions
- Filter by income or expense
- Store data using LocalStorage

### Financial Dashboard
- Total Income
- Total Expenses
- Current Balance
- Savings Rate

### Analytics
- Spending by category
- Interactive doughnut chart
- Monthly spending trend
- Financial insights based on transaction data

### Budget Management
- Set category-wise budgets
- Track spending against budgets
- View remaining budget
- Budget usage percentage and progress bars
- Warning for high budget usage
- Overspending alerts
- Delete budgets

### Financial Goals
- Create financial goals
- Track target and saved amounts
- Add savings
- View progress percentages and progress bars
- Delete goals

## Tech Stack

- HTML
- CSS
- JavaScript
- Chart.js
- Browser LocalStorage
