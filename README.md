# AligeIQ

A personal finance intelligence web application to track transactions, manage budgets and goals, and understand spending through interactive analytics.

## Features

- User registration and login
- Add, edit, delete and search transactions
- Income and expense tracking
- Financial dashboard
- Category-wise spending analysis
- Monthly spending trends
- Budget tracking and alerts
- Financial goal tracking
- Interactive charts and insights

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- PostgreSQL
- Neon
- Chart.js
- bcrypt
- JWT

## Deployment

- Frontend: Vercel
- Backend: Render
- Database: Neon PostgreSQL
